Explanation of AI/model/API used

Model approach

This app uses a browser-based simulated supervised learning model. Learners choose features, train the model, inspect weighted outputs, receive AI-style explanations, and hear explanations using the Web Speech API. The 2.5D model is built with HTML, CSS transforms, and JavaScript so it works without paid API keys.

Complete front-end internship project: learning modules, 2.5D model, AI explanation, voice, quiz, simulation, and progress tracking.
